MuMu Player — Connect ADB

MuMu Player (both MuMu 12 and MuMu 15) ships with ADB reachable by default and normally connects to Bari Plux Tool automatically. This page covers the connection requirements and what to check if it doesn't.

Last updated: 31 August 2026 Applies to MuMu 12 and 15
Why ADB matters The automatic path If it won't connect

1Why ADB Matters

ADB is how Bari Plux Tool reads and manages your PUBG Mobile install inside MuMu — FPS presets, keymap backup/restore, Active.sav backup, and file transfers all go through this connection.

2The Automatic Path (Try This First)

  • Set your MuMu install folder once in BPT's Settings → Emulator Profile (the folder that contains nx_main).
  • Open MuMu Player and let it fully boot to its home screen before opening BPT.
  • In BPT, go to Home and click Connect Emulator.
  • If you run multiple MuMu instances at once, make sure the profile selected in BPT's Settings (MuMu 12 vs. MuMu 15) matches the instance you actually want BPT talking to.

MuMu doesn't have a separate "enable ADB" toggle to hunt for in most versions — the bundled ADB bridge is already on. If BPT still can't see it, the install path is almost always the culprit.

3If It Still Won't Connect

  1. Double-check Settings → Emulator Profile → MuMu Install Path in BPT actually points at MuMu's real install folder — use the Detect button there instead of typing it by hand.
  2. Click BPT's Repair ADB (Home → Quick Actions), then try Connect Emulator again.
  3. Close every running MuMu instance, reopen only the one you want to use, and wait for its home screen before reconnecting.
  4. Add BPT's install folder to your antivirus/firewall exclusions if a security tool may be blocking its bundled adb.exe.
