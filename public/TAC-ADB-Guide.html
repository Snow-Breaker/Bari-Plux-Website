TAC ("New GameLoop") — Enable ADB

TAC (Tencent Android Connect, also shown as "GameLoop" in newer installs) is a genuinely different engine from legacy GameLoop — it has no Home screen or app market by default, so reaching Android's own Settings takes one extra step the first time.

Last updated: 31 August 2026 Has an app market + Home screen? Use the legacy GameLoop guide instead.
Why it's different The automatic path If BPT can't reach Settings Worth knowing

1Why This Is Different From Other Emulators

TAC's launcher boots directly into one app (normally the game itself) with no Home screen to switch away from — so there's no obvious way to reach Android's Settings app to turn on USB debugging, the same way you would on GameLoop, MuMu, or LDPlayer. Bari Plux Tool already knows how to work around this automatically.

2The Automatic Path (Do This)

  1. In BPT's Settings → Emulator Profile, select TAC.
  2. Open TAC as you normally would.
  3. In BPT, go to Home and click Connect Emulator. If USB debugging isn't on yet, BPT automatically launches TAC directly into Android's own Settings screen for you — no file manager, no extra app install, nothing to download inside the emulator.
  4. From that Settings screen, the rest is the one manual step nothing can automate: go to About phone, tap Build number about 7 times until it says "You are now a developer," then open the new Developer options entry and toggle USB debugging on.
  5. Click Connect Emulator again in BPT — it should connect immediately, no restart needed.

This is a one-time step per TAC install. Once USB debugging is on, it stays on — you won't need to repeat this the next time you open TAC.

3If BPT Can't Reach the Settings Screen Automatically

  1. Make sure TAC is fully closed and reopened once, then try Connect Emulator again — a half-started session can interfere with the automatic launch.
  2. Click BPT's Repair ADB (Home → Quick Actions), then try again.
  3. Note: TAC's Wireless debugging toggle doesn't work in this environment (there's no real Wi-Fi radio inside the virtual device) — this is expected and not something to troubleshoot. USB debugging is the one you need, and it's enough on its own.

4Worth Knowing

  • TAC reports a different spoofed device model almost every session — this is normal for this specific emulator and not a sign anything is broken. It doesn't affect whether BPT can connect or apply FPS/Active.sav/keymap features.
  • The Companion Agent (used elsewhere for live screen resolution/refresh-rate readouts on the Home card) cannot run on TAC — TAC only ever runs the one app it was provisioned for and blocks any other app from starting, by design. This isn't a bug to troubleshoot; ADB-based features (FPS presets, Active.sav, keymap) work normally regardless.
