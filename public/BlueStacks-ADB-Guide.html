BlueStacks — Enable ADB

Unlike GameLoop, MuMu, and LDPlayer, BlueStacks ships with ADB switched off by default — this one manual toggle is required before Bari Plux Tool can connect to it at all.

Last updated: 31 August 2026 · Applies to BlueStacks 5

Why this step is required

BlueStacks disables its Android Debug Bridge by default for every instance. This is a one-time setting per instance, not a per-launch step — once it's on, it stays on until you turn it off again.

Turn on ADB in BlueStacks

  1. Open BlueStacks and start the instance you use for PUBG Mobile.
  2. Click the gear icon (Settings) in the side toolbar.
  3. Go to the Advanced tab.
  4. Find Android Debug Bridge and turn the toggle on.
  5. BlueStacks will show a message like "ADB is listening on 127.0.0.1:port" — the port number changes on every restart, but Bari Plux Tool reads it automatically, so you don't need to note it down yourself.

Connect from Bari Plux Tool

  • In BPT's Settings → Emulator Profile, select BlueStacks.
  • With BlueStacks running and ADB enabled as above, go to Home and click Connect Emulator.
  • If you restart BlueStacks, the ADB toggle stays on from before — you only need to repeat the steps above if you reset BlueStacks or create a new instance.

Source

These steps match BlueStacks' own official support documentation: How to enable Android Debug Bridge on BlueStacks 5.
