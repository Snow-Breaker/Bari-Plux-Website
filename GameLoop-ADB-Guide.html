GameLoop — Connect ADB

GameLoop is the most common setup and usually connects to Bari Plux Tool with zero manual steps. This page covers what "connected" actually needs, and the fallback if it doesn't happen automatically.

Last updated: 31 August 2026 Applies to legacy GameLoop
Installed recently with no app market? Use the TAC guide instead.
Why ADB matters The automatic path If it won't connect Worth knowing

1Why ADB Matters

ADB (Android Debug Bridge) is how Bari Plux Tool talks to the Android system running inside GameLoop — reading device info, applying FPS/graphics presets, managing keymaps, and backing up your PUBG Mobile save data all go through this connection. Without it, BPT can still change Windows-level settings, but anything that touches the game itself needs ADB.

2The Automatic Path (Try This First)

  • Open GameLoop and let it fully load to its home screen before opening BPT.
  • In BPT, go to Home and click Connect Emulator (or Manage on the Emulator card).
  • If BPT reports the Companion Agent isn't installed, click Install Agent — this is a one-time step per GameLoop install.
  • If ADB was recently blocked by GameLoop itself, BPT's Repair ADB button (Home → Quick Actions) flips GameLoop's own ADB bridge registry setting back on and restarts the ADB server — no manual registry editing needed.

For most users this is the whole story — GameLoop ships with ADB reachable by default, and BPT's own tools handle the rest.

3If It Still Won't Connect

  1. Close GameLoop completely (not just minimize), then reopen it and wait for the home screen.
  2. In BPT, click Repair ADB, then try Connect Emulator again.
  3. Check that no antivirus or firewall rule is blocking BPT's bundled adb.exe — add BPT's install folder to your antivirus exclusions if you're unsure.
  4. Restart your PC if GameLoop was recently updated — a stale background service can hold the ADB port open.

4Worth Knowing

GameLoop and Tencent's newer "TAC" emulator (also branded GameLoop, installed to a similar-looking folder) are genuinely different products under the hood — if your install has no app market and boots straight into one game, follow the TAC guide instead, not this one.
