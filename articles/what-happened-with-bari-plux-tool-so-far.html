What Happened with Bari Plux Tool So Far

Hello everyone, I apologize for the delay in the new update. My goal was to make Bari Plux Tool a high-performance app that supports all emulators. Here is the full story of what happened — and where things are headed next.

2025 4 min read v2.3 → v3.0.0 Built from scratch
Vision Design feedback The rebuild What's coming Timeline

1The Vision Behind Version 2.3

The goal was ambitious: build a high-performance application that supports all emulators. Version 2.3 was developed and released exclusively on the dev channel to test this vision in real-world conditions.

However, during testing a major issue surfaced — the app worked slowly and was not stable across all specific PCs. Beyond performance, version 2.3 also had significant UI/UX problems that made features and their functions difficult to understand, with some features being outright unintelligible.

2A Design That Missed the Mark

The new design introduced in version 2.3 looked good from a developer's perspective. But feedback from others painted a different picture — it was described as a "fantasy app" with a third-party background, over 100 images (icons), and too many colors everywhere.

Sometimes the hardest but most necessary choice is knowing when to start over.

3Built From Scratch With a New Foundation

Build 3.0.0 was written fresh from scratch and built with a focus on performance and stability. The entire app UI was changed from WPF to WinUI 3 Fluent design, which will look exactly like an official Windows app and be easy to use.

This is not an incremental update — it is a complete rebuild. Every layer of the application was rethought with the end user in mind: faster, cleaner, and more reliable than anything before it.

For more information and the exact release date, follow the official Bari Plux social media channels.

4What's Coming Next

Bari Plux Tool (App) version 3.0.0 will be released this week for developers, with the main release for everyone following soon. It is estimated to be released by the end of this week or, at the latest, in the first few days of next week for any necessary fixes.
